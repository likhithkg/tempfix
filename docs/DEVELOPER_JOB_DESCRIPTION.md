### Flutter + Full Stack Developer — KrishiMithra (AgriTech Startup)

**Company:** KrishiMithra Private Limited  
**Location:** Remote (India preferred) / Hybrid  
**Type:** Full-time or Contract  
**Experience:** 2–4 years  
**Compensation:** As per industry standards + equity discussion for exceptional candidates

---

**About KrishiMithra**

KrishiMithra is an agricultural super-app connecting farmers, exporters, labourers, equipment owners, and plant vendors on a single platform. We cover 10+ services: crop disease detection, a farm-to-buyer marketplace (GreenBazaar), labour hiring, equipment rental, export order management, a multilingual AI chatbot, weather forecasts, and more.

The app is built in Flutter, backed by Firebase and a Node.js/Express API, and supports 6 Indian languages (English, Hindi, Kannada, Tamil, Telugu, Marathi). The codebase is complete and functional. You will not be building from scratch.

---

**The Role**

We need one strong mid-level Flutter developer to take an existing, working app to production quality and Play Store launch. The codebase is in good shape. Your job is to fix the known production blockers, harden the backend, add test coverage, and ship.

You will work directly with the founder and will have Claude (AI engineering assistant) available as a productivity tool for code analysis, documentation, and debugging assistance.

---

**What You Will Do**

- Rename Android application ID and set up production release signing for Play Store
- Add rate limiting and input validation to the Node.js/Express backend
- Implement FCM push notifications across relevant modules
- Write widget and unit tests for critical user flows
- Debug and fix crash reports from internal testing
- Maintain Firestore security rules as new features are added
- Coordinate Play Store submission (assets, listing, privacy policy)
- Review and manage dependency updates responsibly
- Work in a branch-protected GitHub workflow (PR reviews, no direct commits to main)

---

**Required Skills**

- Flutter / Dart — 2+ years, must have production experience
- Firebase Authentication (email, phone OTP, Google Sign-In)
- Cloud Firestore (queries, security rules, indexes)
- Google Play Store release process (signing, APK/AAB, Play Console)
- Android build system (Gradle/Kotlin DSL)
- Node.js / Express — ability to read, maintain, and extend existing routes
- REST API integration
- Git / GitHub — branch workflow, PRs, code review

**Important Skills (not dealbreakers, but expected)**

- Cloudinary image upload integration
- Location services (geolocator, Google Maps Flutter)
- Flutter l10n (ARB files, flutter_localizations)
- MongoDB basics (we use Atlas for user sync)
- Supabase storage (profile photos)
- Performance optimisation (Firestore pagination, image caching)

**Nice to Have**

- iOS Flutter development (Xcode, provisioning profiles)
- FCM implementation experience
- Flutter widget/integration testing experience
- CI/CD setup (GitHub Actions)

---

**What You Will NOT Do**

- Redesign the architecture (it's complete)
- Rewrite working modules
- Handle business decisions or product roadmap (that's the founder's role)
- Need to be an expert in every area — Claude handles code analysis and suggestions

---

**Security Expectations**

- You will sign an NDA and IP Assignment Agreement before receiving code access
- You will never request or store production credentials (MongoDB, Cloudinary, Firebase service account)
- All commits go through PR review — no direct pushes to main
- You will report any suspected security vulnerability immediately

---

**Hiring Process**

1. Resume review
2. GitHub portfolio review (we will ask you to explain your own code)
3. 30-minute video call (background, motivation, availability)
4. 2–3 hour technical test (Flutter + Firebase task, provided as a brief)
5. Code review discussion of your test submission
6. Small paid trial task (1 week, paid)
7. Final call + contract

---

**Apply with:**
- Resume/CV
- GitHub profile link (required — we will look at actual code)
- One sentence: the last app you shipped to the Play Store and what your specific contribution was
